# lab-personal: what one user's own labeled dictation can teach VTT (state 2026-11-07, Obama practice user)

- **Rule.** A clip is read only by layers built from `personal.earlier(records, i)`: the same user's labeled clips stored before it. `tests/test_personal.py` poisons the clip's own label, later clips and other users' clips to check this.
- **Metric: length-matched lift.** Use `personal.lift(reads, stts, m, nearest=personal.LIFT_NEAREST)`: the read's score vs its own STT, minus its mean score vs the 10 other turns closest in STT word count. Never use raw accuracy or plain lift for this. A content-free filler (the user's top words, repeated to rate × duration) gets plain word lift +0.28, beating every arm. Muse's whole plain word lift (+0.075) comes from length: a filler of Muse's word counts scores +0.078.
- **Free arms** (n=76, paired vs VTT · Muse at word +0.004 / viseme +0.010): `scorer_personal` +0.013 / +0.012 (38 up/24 down, p=0.10), inconclusive. `slot_lm` +0.008, `lm_rescore` +0.005, `viseme_personal` +0.007 and `scorer_staged` +0.004 are all parked (p ≥ 0.3).
- **Parked, why:** `scorer_staged`'s exact-match labels are ∅ on dictation (the pool never holds the STT), so ∅ wins and the reads come out empty. Muse's viseme stream is at chance (0.166, 15 codes per 70 true), so personal viseme costs fit noise. Reopen viseme costs if the stream acc is above 0.21.
- **Few-shot (paid)** = 2 most recent earlier clips, one 4x4 image + STT each, `muse_sampler.sample_open(examples=)`. Result, n=38, K=5, $5.40: word lift +0.008 → +0.026 (20/18, p=0.87), viseme lift +0.018 → +0.047 (23/15, p=0.26). Raw viseme 0.24 → 0.31 (p<0.001), but that is the 2x longer reads (9 → 19 words). Parked; reopen at n ≥ 80, or with examples picked by content rather than recency.
- **Learning curve:** not run. Nothing has shown lift at full history, so there is nothing to curve yet. Run it with `--curve 5,10,20,40`.
- **Commands.** `uv run --env-file .env python tools/exp_personal.py --user U [--curve 5,10,20,40] [--source exp:lab-personal-fewshot:U --only-source] [--save]`. `uv run --env-file .env python tools/exp_personal_fewshot.py --user U --targets N [--save]`: pays only for new targets, ≤4 calls in flight, stored as `exp:lab-personal-fewshot:U`.
