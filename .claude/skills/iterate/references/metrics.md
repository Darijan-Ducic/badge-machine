# Metrics: which one, chance levels, turns per arm (`metrics.py`, run record `metrics-c07161c9`)

Measured on 41 turns of `practice:obama-weekly:obama`, reader VTT · Muse. On 40 of the 41 turns the K=5 top hypotheses are all different, so "most common" just returns sample 0.
- **Turns per arm:** run ≥ 40 paired turns. The minimum detectable effect (paired t, 80% power, α .05) at n = 10/20/40/80 is: word acc 0.045/0.030/0.020/0.014, viseme acc 0.054/0.036/0.025/0.017, nearest-length viseme lift 0.034/0.023/0.016/0.011. With 6–10 turns, any difference under about 0.05 is noise.
- **Sign test:** this is how many NON-tied turns you need for 80% power: P(up) 0.9 → 12, 0.8 → 20, 0.75 → 30, 0.7 → 49. Ties under the null are 62% (word) and 28% (viseme), so divide by (1 − ties) to get total turns. `metrics.sign_turns_needed(p)`.
- **Your own noise:** `metrics.split_half_sd(sample_texts, stts, metrics.per_turn_viseme_acc)` gives the null SD from the stored K samples. Then `metrics.mde_paired(sd, n)` or `metrics.turns_needed(effect, sd)`.
- **Gaming, word and viseme acc:** a constant string of the speaker's most frequent words beats VTT · Muse on both. Word acc: "the to of in we" scores 0.080 vs 0.033. Viseme acc: the top-19 words score 0.295 vs 0.246. Other baselines: a different turn's read gets 0.009 / 0.215, shuffled STT −0.157 / 0.178, "we need to keep going together" 0.032 / 0.183. These scores rise with any read that is longer or more generic.
- **Gaming, the other metrics:** phoneme acc, viseme_acc_norm, content_recall and keyword_hit all lose to frequent-word strings too (content-word strings score 0.171 / 0.340 / 0.175 / 0.707 vs Muse 0.151 / 0.246 / 0.009 / 0.073). NEVER report them alone.
- **Impostor-corrected metrics:** a constant read scores exactly chance on these. `viseme_lift` has chance 0; `sentence_id` has chance top1 = 1/N and percentile = 0.5. Length still leaks: a filler string with the STT's word count gets lift +0.175, against +0.057 for Muse.
- **Primary metric = `metrics.viseme_lift(vtts, stts, nearest=10)`.** Pair it with word acc as the headline. With length-matched impostors VTT · Muse gets +0.009, filler with the STT's word count +0.014, and the null SD is 0.034. So today's above-chance viseme score is length, not lip content. A real gain must show up here.
- **Always report:** n, the paired delta with its bootstrap CI, the delta in nearest-length lift, and mean read words against mean STT words (19.3 STT vs 9.2 read). If a change makes reads longer and raises viseme acc but not lift, it is gaming. Reject it.
