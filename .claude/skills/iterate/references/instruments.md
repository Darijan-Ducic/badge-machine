# Instruments

Instruments report evidence; you decide.
Line numbers are as of a87c507, except server.py, clips.py, tools/compare.py and tools/diagnose.py, which are cited at cca8ac7; if a cited line moved, grep the symbol.
⚠ = side effect: the call spends money (Meta Model API or Gemini), writes a store, or moves a pointer (`current` / `live`).

## Which instrument answers which question

Run every command from the repo root: the file fallbacks are cwd-relative (`data/runs` runs.py:16, `data/versions` versions.py:46, `data/clips` clips.py:34, `data/sessions` sessions.py:47).
`uv run --env-file .env` sets `MONGODB_URI`, so every store becomes MongoDB Atlas (database `MONGODB_DB`, default `badge_machine`; runs.py:60-64, versions.py:359-363, clips.py:167-171, sessions.py:256-260); without it every store falls back to `data/...`. The same file supplies `MODEL_API_KEY`, which every paid Meta call needs (muse_video.py:28-30, asr.py:31, sam.py:44-45). Each row is detailed, with citations, in its section below.

## Instruments

### tools/experiment.py (CLI)
- **For**: replays stored raw clip outputs under a baseline knob set and variant knob sets, same clips in the same order, and prints one comparison table (tools/experiment.py:1-14).
- **Invoke**: `uv run python tools/experiment.py (--records PATH | --simulate SEED:N) [flags]`; add `--env-file .env` to save to MongoDB (tools/experiment.py:5-6, 12). `--records`/`--simulate` are a required mutually exclusive group (:82-84). Flags (argparse :83-96):
  - `--records PATH` default none, JSON lines of raw clip records in replay order (:76-77); a `tools/compare.py --export` file is one JSON array, so convert it first (see tools/compare.py below) · `--simulate SEED:N` default none, N simulated clips from `tests/simulator.py`, no network (:70-75).
  - `--sim-knobs JSON` default none, read as `{}`; keys `k=5, muse=1.0, closed=1.0, gemini=1.0, visemes=0.0, miss_rate=0.0, bad_quality=0.05, miss_bad_quality=0.9, no_speech=0.05, fail=0.0` (:73; tests/simulator.py:74-75).
  - `--dataset ID` default `sim:seed=<seed>:n=<n>:<knobs json>` with `--simulate`, the file's stem with `--records` (:86, :75, :77) · `--user ID` default None, stored as `user_id` (:87, :113).
  - `--baseline SPEC` default None = `experiment.DEFAULTS` (:88, :112; experiment.py:62-68) · `--variant NAME=SPEC` `append`, default `[]`, repeatable; a missing `=` or name is a parser error; zero variants runs only the baseline (:89, :100-104).
  - `--hypothesis TEXT` `append`, default None, once for all variants or once per variant (:90, :59-66, :106) · `--author {agent,human}` default `human` (:91).
  - `--system-version ID` default None (:92) · `--parent-version ID` default None (:93) · `--candidate-version ID` `append`, default None, once or once per variant; a free-text note that never touches the registry (:94, :107).
  - `--store DIR` default None = MongoDB `runs` if `MONGODB_URI` is set, else `data/runs/` (:95; runs.py:60-64) · `--no-save` `store_true`, default False (:96, :118).
  - SPEC is inline JSON when it starts with `{`, else a JSON file path (:55-56); knobs `costs, drop, stages, pool_cap, readiness`, unknown knobs raise (experiment.py:92-114). Records without a top-level `stt` are dropped; a scored record needs `samples` and `bank`, while `closed`/`gemini` are optional (experiment.py:214-218).
- **Reports**: line 1 `dataset <id>: <n> clips with STT; heldout = clips <a>-<b>` (:115-116); one row per run (`baseline`, then the variant names), columns `run clips "VTT train" "VTT heldout" word viseme top-3 Gemini Muse pool "send prec" "send cov" gate hash` (:27-41), where `word`/`viseme`/`top-3` are held-out and `VTT train`/`Gemini`/`Muse`/`pool` come from the train stream (:44-45); last line `saved N runs to <store>: <ids>` (:121-122). Saved records keep no per-clip held-out rows (experiment.py:312).
- **Writes / pointers**: ⚠ one run record per config (baseline plus each variant) via `runs.save` unless `--no-save` (:118-122), to `--store DIR/<id>.json`, else MongoDB `runs`, else `data/runs/<id>.json` (runs.py:20-28, 39-46, 60-68). Creates no versions; moves neither `current` nor `live` (:23-25).
- **Cost**: free; it replays stored outputs or simulates, and no flag makes it paid (:9-10; experiment.py:7-8). `cost_per_clip` is an estimate priced from stored `usage` (experiment.py:163-179).
- **Safe use**:
  - The `gate` pass/fail column compares held-out SENTENCE accuracy (`vtt_acc_heldout` strictly greater than the baseline's, experiment.py:330), which is 0 by construction on natural speech (exact-match labels), so judge on `word` (word_acc) and `viseme` (viseme_acc). Nothing reads that label.
  - The loop baseline uses k=3 (versions.py:175; evaluator.py:122-123) while experiment.py and the UI use all 5 stored samples (experiment.py:217; clips.py:37, 261), so compare like with like: never set an experiment row beside a loop staircase number.
  - Exploratory runs: `--no-save` or `--store /tmp/...`. Runs you cite as evidence: save with `--author agent` and a `--hypothesis`.

### experiment.py (library)
- **For**: the replay harness behind the CLI: splits, per-split evaluation, run records and the experiment gate (experiment.py:1-39).
- **Invoke** (Python, repo root on `sys.path`): `resolve(spec: dict | None) -> dict` (:92) with `DEFAULTS` (:62-68) `costs=None` (= `data/viseme_costs.json`), `drop=[]`, `stages={full:60, core:30, temperature:10, defaults:0}`, `pool_cap=24` (candidates.py:37), `readiness={n_min:5, window:5, acc_min:0.8}` (readiness.py:15-17); stage names must come from scorer, minimums distinct, one of them 0 (:100-102); `pool_cap` in 2..24 (:111); unknown knobs raise (:95-96) · `config_for(records, spec, dataset) -> dict` (:127) · `order_of(records) -> str` (:121) · `word_acc(vtts, stts)` (:153) · `viseme_acc(vtts, stts)` (:158) · `clip_cost(record)` (:173) · `splits(records) -> {train, heldout, test}` (:185) · `evaluate(records, config, split) -> dict` (:277), `split` one of `("train","heldout","test")`, no `limit` parameter · `run(records, spec=None, *, dataset, name, baseline=None, user_id=None, hypothesis="", author="human", system_version=None, code_commit=None, candidate_version=None, parent_version=None) -> dict` (:294-297) · `compare(records, variants, *, dataset, baseline=None, variant_notes=None, **notes) -> list[dict]` (:353-354).
- **Reports**: `evaluate` returns `clips, word_acc, sentence_acc, viseme_acc, top3_acc, gemini_acc, muse_acc, pool_recall, autosend_precision, autosend_coverage, cost_per_clip` (:261-273). Splits are chronological over records with `stt`: train `[0, n*3//5)`, heldout `[n*3//5, n*4//5)`, test `[n*4//5, n)` (:187-193). `word_acc` = 1 − word edits / STT words and can go below 0 (:153-155, :254, :263); `viseme_acc` = 1 − viseme edits / STT visemes (:158-160). `run` returns the run record (:331-350), needs ≥3 labelled clips (:308-309) and computes train + heldout only (:311-312).
- **Writes / pointers**: nothing; `run`/`compare` return records and the caller saves them (tools/experiment.py:118-120). Moves neither `current` nor `live`.
- **Cost**: free (:7-8). Re-fits the scorer per train clip (:243) and once per held-out or test split (:246).
- **Safe use**:
  - Never call `evaluate(records, config, "test")`: it runs with no guard (experiment.py:277-283). Two tools can score the test split: `tools/compare.py --split test --final` for code versions (tools/compare.py:12, 265-276) and `tools/iterate.py --final` for registry versions (tools/iterate.py:59-63). Use exactly ONE, once, at the end of a run, only when the user asks.
  - A baseline must have run on the same dataset id and clip order, else ValueError (experiment.py:305-306); reuse one `--records` file per comparison.

### tools/iterate.py (CLI)
- **For**: four modes: the Muse-proposed self-improvement loop, `--final` (test split), `--show` (version staircase), `--promote` (move `live`) (tools/iterate.py:1-12).
- **Invoke**: `uv run --env-file .env python tools/iterate.py [flags]` (tools/iterate.py:4-8). Argparse (:34-44):
  - `--records PATH` default None; a `.json` list or a `.jsonl` (:27-29); required for the loop and for `--final` (:55-56). Only records with a top-level `stt` are scored (evaluator.py:56-59); a missing `samples` or `bank` silently counts as empty (evaluator.py:122, 127-128).
  - `--registry DIR` default None = MongoDB if `MONGODB_URI` is set, else `data/versions` (:35, :47; versions.py:359-363).
  - `--iterations N` int, default `20` (:36) · `--patience N` int, default `PATIENCE` = `5` (:37; iterate.py:36) · `--budget USD` float, default `1.0` (:38; `iterate.run`'s own default is `math.inf`, iterate.py:521) · `--free-only` store_true, default False (:39) · `--min-gain PTS` float, default `MIN_GAIN` = `1.0` (:40; iterate.py:33).
  - Mutually exclusive group (:41-44): `--final` store_true · `--show` store_true · `--promote VERSION` default None.
- **Reports**: loop: one line per step `[<iteration>] <decision> <version> <op field=value...> — <reason>` (iterate.py:379); stop lines `stop: N consecutive changes without adoption` / `stop: budget spent ($x of $y)` / `stop: the proposer has no more ideas` (iterate.py:533, 536, 540); then the staircase, columns `it version kind change held-out decision current` (iterate.py:570-581; tools/iterate.py:67). `--final`: `test split, <vid>: <json of the 8 metrics>` (:62). `--show`: the staircase rebuilt from the registry (iterate.py:555-567). `--promote`: `live -> <vid>` (:50). Nothing prints the failures or per-clip results (iterate.py:484-496).
- **Writes / pointers**: ⚠ loop on an empty registry creates `sys-v1` and sets both `live` and `current` to it (iterate.py:384-385; versions.py:426). ⚠ Each iteration creates candidate `sys-v<seq>` with `author="agent"` (iterate.py:513-516), records its train/heldout metrics and cost (iterate.py:428-432, 456-459), then calls `adopt` (moves `current`) or `reject` (iterate.py:460-464). The gate adopts iff held-out `word_acc` gains ≥ `--min-gain` points AND held-out `viseme_acc` drops ≤ 0.5 points (iterate.py:72-80, 33-34). The loop never moves `live` (:12). ⚠ `--final` writes `metrics.test` on `current`, no pointer moves (iterate.py:547-552). ⚠ `--promote V` moves `live`; V must have status `adopted` (:48-51; versions.py:478-484). `--show` writes nothing (:52-54).
- **Cost**: ⚠ loop mode is paid by default: the proposer is always `MuseProposer`, one Muse Spark chat call per iteration plus at most one retry (:64; iterate.py:300-319), and no flag gives a free proposer. `--free-only` only removes the paid `set_prompt_hint` op (iterate.py:119-121; versions.py:269-270); the proposer calls still cost money. Spending is capped by `--budget` (iterate.py:535-537, 509-511). Evaluations are free replays (iterate.py:339-344). `--final`, `--show` and `--promote` are free.
- **Safe use**:
  - Loop mode: run it ONLY with `--registry /tmp/iterate-scratch-<date>-<n>`, a new `<n>` for every run because leftover candidates are re-judged on restart (iterate.py:529), never the default registry (MongoDB `versions` under `--env-file`, else `data/versions`), because it adopts on its own numeric gate (iterate.py:460-462) and moves `current`. It always calls the Muse proposer (paid, up to `--budget`, default $1.00). Treat its adoptions as suggestions to re-check with compare/experiment evidence: Muse proposes, you decide. Run it in the foreground and watch it; it loops up to `--iterations` with no human (iterate.py:531).
  - `--promote` only with the user's explicit OK in this conversation.
  - `--final` only once, at the end of a run, when the user asks, and never in a run that already used `tools/compare.py --split test --final` (one test number per run); `final()` does not enforce this and overwrites `metrics.test` on every call (iterate.py:547-552; versions.py:444-454). `--show` is the read-only mode.

### iterate.py (library)
- **For**: the loop's parts, callable one at a time: the gate, the failure summary, the proposers, `run`, `final` and the staircase (iterate.py:1-20).
- **Invoke**: `gate(parent, candidate, min_gain=MIN_GAIN) -> (bool, str)` (:72) · `summarize(failures, n_clips, max_examples=MAX_EXAMPLES=12)` (:89, :37) · `tried_ideas(versions, refused)` (:107) · `change_space(free_only)` (:119) · `FakeProposer(script, respect_memory=True)` (:134-139) · `proposal_schema(context)` (:189) · `build_prompt(context, min_gain=MIN_GAIN)` (:274) · `MuseProposer(client=None, model=MODEL, min_gain=MIN_GAIN)` (:289) with `.propose(context, check)` (:292), Muse at temperature 1.0, `reasoning_effort="low"` (:301-304) · `run(records, registry, proposer, evaluator, *, baseline=None, iterations=20, patience=PATIENCE=5, budget=math.inf, free_only=False, min_gain=MIN_GAIN=1.0, log=None) -> list[step]` (:520-522) · `final(records, registry, evaluator, version=None) -> dict` (:547) · `history(registry)` (:555) · `staircase(steps) -> str` (:570). Constants `MIN_GAIN=1.0, MAX_VISEME_DROP=0.5, PILOT_CLIPS=20, PATIENCE=5, MAX_EXAMPLES=12, MAX_CONFUSIONS=5` (:33-38).
- **Reports**: `run` returns steps `{iteration, version, kind, change, hypothesis, decision (adopted|rejected|refused), reason, heldout_word_acc, current, current_word_acc}` (:376-378); `final` returns the test metrics (:550-552); `summarize` counts each cluster, `pool_miss` (STT not in the pool), `abstained` (STT in the pool, ∅ won), `ranked_wrong` (STT in the pool, another candidate won), with its top 5 STT→VTT confusions and up to 12 examples, newest first, round-robin (:40-44, :83-104). Points are `round(100*x, 6)` (:68-69).
- **Writes / pointers**: ⚠ registry versions and pointers through `create_baseline`, `create_candidate`, `record_metrics`, `add_cost`, `set_pilot`, `adopt`, `reject` (:385, :513, :362, :432, :444, :462-464); `current` moves on adopt (versions.py:470); `live` + `current` are set when the baseline is created in an empty registry (versions.py:426). It never calls `promote`.
- **Cost**: free with `FakeProposer` and a replay evaluator; ⚠ paid with `MuseProposer` (`MUSE_PRICE = (1.25, 4.25)` $/1M tokens, :39, :306-307). The paid pilot (first 20 held-out clips, iterate.py:434-449) is unreachable with `ExperimentEvaluator`, which raises `PilotUnsupported` (evaluator.py:221-223).
- **Safe use**:
  - `gate` and `summarize` turn your own metrics and `evaluator.failures(...)` output into evidence; the boolean `gate` returns is a threshold, not your decision.
  - Never call `run` with `MuseProposer` and the library default `budget=math.inf`; give it a fresh `Registry("/tmp/iterate-scratch-<date>-<n>")` per run (`run` re-judges leftover candidates, iterate.py:529; a str path is a file store, versions.py:362).
  - The `_NoTest` guard exists only inside the loop (iterate.py:325-336, 351), and the tried-ideas memory shows the proposer each past change's held-out delta (iterate.py:107-116, 490), so loop adoptions are tuned on held-out aggregates.

- **Cost**: free.
- **Safe use**:
  - Read methods are always safe. Call `adopt` only on your own compare/experiment evidence; call `promote` only with the user's explicit OK in this conversation.
  - There is no rollback: to revert, create an inverse-change candidate (versions.py:465-468). A change that leaves the config unchanged is refused (:271-273).
  - Never write `record_metrics(vid, "test", ...)` yourself; the one test write is `--final`.

### runs.py

## What runs without you
1. **iterate.run loop** (iterate.py:520-544; tools/iterate.py:64-66): proposes, judges and adopts up to `iterations` times; stops on `patience`, budget or a dry proposer. Account for it by running loop mode only against a fresh `--registry /tmp/iterate-scratch-<date>-<n>`, in the foreground.
2. **Adopt on the numeric gate** (iterate.py:460-462; versions.py:470): `current` moves whenever `gate()` passes. Account for it by re-checking every `adopted` line with compare/experiment evidence before you record it in the real registry.
3. **Baseline auto-creation** (iterate.py:384-385; versions.py:426): the first loop run on an empty registry creates `sys-v1` and sets `live` and `current`, in MongoDB `versions` under `--env-file .env`. Account for it by always passing a scratch `--registry`.
4. **Resume judging** (iterate.py:529): every leftover `candidate` is evaluated and gated again on start. Account for it by using a fresh `/tmp/iterate-scratch-<date>-<n>` per loop run.
5. **Stale rejection** (iterate.py:422-424): a candidate whose parent is no longer `current` is auto-rejected. Account for it by reading such a rejection as bookkeeping, not as evidence against the change.
6. **Refusals** (iterate.py:394-414, 500-503, 504-511): invalid, already-rejected, duplicate-config, evaluator-unsupported and over-budget paid proposals are refused unevaluated. Account for it by knowing a duplicate-config refusal also blocks re-testing a config after a code edit (iterate.py:405-409); use `tools/compare.py` for that.
7. **Proposer retry** (iterate.py:300-318): MuseProposer re-asks once with the refusal reason. Account for it by budgeting up to two Muse calls per iteration.
8. **Scorer stage unlock by label count** (scorer.py:27, 42-44, 84): `defaults` < 10 ≤ `temperature` < 30 ≤ `core` < 60 ≤ `full`. Account for it by citing the labelled count beside every accuracy; a jump at 10, 30 or 60 labels may be the stage, not your change.
9. **Auto-send threshold re-tuned** (scorer.py:81, 90-99; fusion.py:38-45): 5-fold out-of-fold threshold at precision 0.9 on every `train(gate=True)`. Account for it by comparing `send prec` / `send cov` only on the same clips.
10. **Weights fitted** (scorer.py:57-65; fusion.py:25-35): L-BFGS-B inside every `train` past `defaults`; never stored. Account for it by reading weights through `tools/diagnose.py recipe`, never from a stored copy.
11. **Re-fit inside clips.process_clip** (clips.py:298, 309, 410, 449; server.py:148-151): every POST /preheat/clip reads back and re-runs stats with a model on the user's earlier clips. Account for it by never treating a preheat response as a held-out number.
12. **Re-fit per dictation turn** (clips.py:462, 410; sessions.py:389-391; server.py:26): in the background. Account for it by reading per-turn VTT in `GET /sessions/<id>` as "the model at that moment".
13. **Re-fit in lip mode** (clips.py:490, 268-269, 276-279): every POST /vtt refits, and `action == "auto"` sends without asking. Account for it by treating any scorer or threshold code change as user-facing.
14. **Re-fit on reads** (GET /stats clips.py:298, 309; GET /readiness clips.py:327; GET /clips clips.py:340, 343-345; GET /clips/<id> clips.py:369): CPU only, no writes. Account for it by recording `labeled` with any number you cite, since it shifts as labels arrive.
15. **Label precedence** (clips.py:245-247): a `user_edit` silently replaces the STT label in every later re-fit. Account for it by checking for new labels when numbers move without a code change.
16. **Evaluator failure re-fit** (evaluator.py:174-176, 183): a model per train clip, diagnostic only. Account for it by reading failure lists as prequential train errors.
17. **Experiment re-fit + gate label** (experiment.py:243, 246, 330): nothing acts on the `pass`/`fail` label. Account for it by judging on `word` and `viseme`.
18. **Tracker knob sweep** (tools/replay.mjs:140-159): grid-searches and picks a best config; prints only. Account for it by deciding yourself and committing any `static/tracker.js` edit as a code change.
19. **Background spending** (sessions.py:44, 124-135, 320-329, 389-391; server.py:43-46, 161): POST /dictation queues paid turns with automatic retries; real users are capped at 50 per day, while practice (`practice:<dataset>:<speaker>`) sessions are uncapped (sessions.py:376-377). Account for it by counting the kept turns you send against the user's budget.
20. **Resume on server start** (server.py:38-40, 176-177; sessions.py:395-410): every start re-queues the pending turns of unfinished sessions on `TURNS`, each a paid turn read. Account for it by checking for pending turns before any start and telling the user (server.py → Safe use).

Not automatic: nothing moves `live` except `create_baseline` (item 3) and an explicit `promote` (versions.py:478-484; tools/iterate.py:48-49); the only runtime read of the registry is `GET /versions`, which returns `payload()` and moves nothing (server.py:19, 103-104), and no VTT path reads `live` or `current` (clips.py:26-32 import no `versions`).
Discrepancies: docs/STATUS.md:50-51 says "No programmatic iteration loop", but tools/iterate.py runs one by default (iterate.py:520-544); trust the code.
